喵化助手

打完字按一下，整段变成喵喵的
电脑版 2.15.0　·　安卓版 3.4.5
一句话说明：这是个电脑 + 手机的小工具。你在 QQ 里打完一句话，按一下快捷键， 它会替你改词、加颜文字、加一句符合语气的尾句。
比如「好的」→「好哒喵！(=^･ω･^=)」
★★★ 装之前，先看这三件事 ★★★
  1. 这个软件【完全免费】。没有广告、没有会员、没有内购。 如果你是花钱买的，说明你被骗了，请立刻找商家退款。
  2. 微信需要额外开一个「读屏服务」才能用。 不开的话，微信里不会生效 —— 这不是软件的 bug，是微信的限制：它只让系统官方的读屏应用读取聊天输入框。 步骤在「六、手机版」里，两分钟就能弄好。
  3. 游戏里用不了。游戏画面是游戏引擎自己画出来的，系统里根本没有「输入框」 这个东西，任何无障碍类软件都读不到。MT 管理器这类自绘界面的编辑器同理。
★★★ 聊天框里有图片时，先别按转换 ★★★
QQ 和微信的输入框没办法把图片放进剪贴板 —— 复制不行，剪切也不行。 而这个程序的原理是「全选 → 复制 → 改 → 粘回去」，所以 框里只要有图片，一次转换就会把图片弄没。
这是对方的限制，程序这边绕不过去（试过用剪切先探测，结果那一步就把图片弄丢了）。 要转换就先把图片去掉，或者等图片发出去之后再改文字。

一、三分钟开始用

  1. 打开程序
    双击 电脑版\Miaohua.exe。会弹出主窗口，右下角托盘也有个猫脸图标。
  2. 确认「生效程序」是 QQ
    打开「设置」页，看「生效程序」是不是 QQ。是的话就不用动—— 意思是只有 QQ 里才会自动转换，别的软件不受影响。
  3. 去 QQ 里打字，按快捷键
    打完一句话，按 Ctrl + Shift + M， 整段就变了。
也可以不用按键。「设置」里打开「停止打字后自动转换」，你停手约 1 秒它就自己变。 第一次用建议先不打开，等你确认效果符合预期再说。

二、三个快捷键

按键作用
Ctrl+Shift+M立刻转换当前这句话
Ctrl+Alt+Shift+P暂停 / 恢复（暂停后所有转换都不生效）
Ctrl+Alt+Shift+R重新读取规则文件
改了快捷键要重开程序才生效——Windows 的全局热键只能在启动时注册。

三、让它说你自己想说的话

所有内容都在 电脑版\rules.txt 里，是个纯文本文件，用记事本就能改。 程序里有「查看规则」按钮直接打开它。

1. 改词（一句话换一个词）

格式是 原文 => 替换成，一行一条：

谢谢你 => 谢谢你喵
哈哈 => 哈哈哈
好的 => 好哒
# 井号开头是注释，不会被读取

2. 加颜文字和尾句

同名的行写几行，就有几个候选，每次随机挑一个，而且不会连着两句用同一个：

后缀 = 喵！
颜文字 = (=^･ω･^=)
颜文字 = (≧▽≦)
开头 = 哼，
开头 = 才、才不是……
结尾 = ，才不是为了你才说的呢……真的不是哦
结尾 = ，哼，别、别误会啊……我只是顺便提一下
「结尾」是最常命中的一类（普通句子都走它）。觉得翻来覆去就那几句， 多写几行「结尾」最有效。

3. 按语气分成不同回法

四、两套风格

外观风格语气风格
管什么颜文字、后缀（喵！ / 喵~）开头、各类结尾
可选萌系 / 元气 / 慵懒 / 撒娇 / 冷淡 / 颜文字在前傲娇 / 黏人 / 慵懒 / 委屈 / 元气 / 应激

「应激」是干什么的

猫受惊或者压力大的时候会炸毛哈气——耳朵往后贴成「飞机耳」、身子压低、 对着靠近的人嘶声警告。这个风格就是那个状态。

风格你打「你好」
傲娇哼，我说啊，你好喵！(￣^￣)，……嗯，好久不见
应激（炸毛）你好嘶——(=｀Д´=)，哈——先退后再说
这是唯一一个猫不是在对你卖萌的风格。台词全是防御、威吓、划清界限—— 不是你平时看到的那种撒娇猫。
后缀是「嘶——」不是「哈——」，因为中文里「哈——」读起来像在笑。
两类是二选一：点外观风格会关掉语气，点语气风格会换成它的句尾装饰。你的词库不会被删。比如「萌系颜文字 + 傲娇语气」。 点外观风格不会动你的语气词库。

还有个「程度」：

  • 轻度——整段只在最后加一次
  • 普通——每句话都加
  • 重度——连逗号处也加（最热闹）

四之二、不想被改内容？用「只加末尾」

语气风格会在句首句尾加话，等于改了你说的内容。有正事要谈、 或者只想要个可爱的句尾，就点「只加末尾」那个按钮（在语气风格那一排的最后）。

模式你打「你好」
傲娇（语气改写）哼，我说啊，你好喵！(￣^￣)，……嗯，好久不见
只加末尾你好喵！(=^･ω･^=)

「只加末尾」做的事：

  • 照旧执行词替换（再见 => 拜拜 之类）
  • 照旧在末尾加后缀 + 颜文字
  • 不在句首句尾加任何话
  • 程度自动设为「轻度」（只在整段末尾加一次）
它不动你的语气词库。点「只加末尾」只是把语气关掉， 你写的那些「结尾 / 开心结尾 / 安慰结尾」一行都不会丢—— 哪天想用回来，点一下「傲娇」就全回来了。
命令行也能切：
Miaohua.exe --style 只加末尾　切到纯净模式
Miaohua.exe --style 傲娇　　　切回语气改写
Miaohua.exe --styles　　　　 看全部可选名字

四之三、中英文切换（2.15 新增）

界面有中文和英文两套。左下角那个按钮点一下就能换，中文 ⇄ English 随时切。

换的不只是界面文字，是整套：
  • 界面 —— 几百处文字全部跟着走
  • 规则 —— 自动换成英文那份（rules-en.txt）， 词库、后缀、颜文字整套都换
  • 外观风格 —— Cute / Cheerful / Sleepy / Clingy / Cold / Kaomoji
  • 语气风格 —— Tsundere（傲娇）/ Needy（黏人）/ Sleepy（慵懒）/ Sad（委屈）/ Cheerful（元气）/ Startled（应激）
  • 颜文字 —— 换成英文圈常见的那些

颜文字为什么换了一套

原来那套里有不少字符在英文用户看来是「乱码」：

原来的问题
(๑•̀ㅂ•́)و✧里面是韩文
ฅ^•ﻌ•^ฅ里面是泰文和阿拉伯文
(￣o￣)　(˘ω˘)　(・_・)日文假名，英文用户不熟

所以英文版用的是 (=^･ω･^=)　(≧▽≦)　♡(>ω<♡)　 :3　>w<　uwu　:D　;w;　 TwT　D:　(-.-)Zzz　＼(^o^)／　 (ﾉ◕ヮ◕)ﾉ*:･ﾟ✧ —— 都是英文聊天里真的会用的。

英文模式下每个单词之间会自动加一个空格。
中文是「汉字后面跟喵」很自然，英文不加空格会连成一个词：
hello + meow~ → hellomeow~ ✗　 hello meow~ ✓

五、智能语气（这个包已经自带模型）

关键字判断有个死穴：我不难过 里有「难过」两个字，它只看得见这两个字。 本机的小模型能读懂否定句。

你打的关键字判断模型判断
我不难过难过 ✗普通 ✓
呜呜呜手机摔了普通 ✗难过 ✓
别理我普通 ✗疑问 ✓

这个包为什么不用装别的东西

模型文件（约 2 GB）和推理程序都放在 电脑版\模型\ 文件夹里了。 你打开程序时，它会自己把模型服务拉起来，十几秒后就能用，不用你开命令行。

启动信息会写进日志（程序里点「查看日志」），找这几行：
model: starting bundled llama-server ...
model: ready at http://127.0.0.1:1234
model: warmed up (happy)
你自己的隐私：模型跑在你自己电脑上，地址是 127.0.0.1（本机回环）， 不联网、不出这台机器。模型只负责判断情绪（回一个词）， 加进你句子里的话始终来自 rules.txt，模型没有能力往你的聊天内容里写字。

不想要模型也行

「设置」里把「开启智能语气」关掉，就完全离线走关键字判断， 程序不会再发出任何网络请求。两类判断都不影响改词和颜文字。

六、手机版

怎么装

  1. 把 APK 传到手机
    微信传、数据线传都行。点开它安装，系统可能提示「未知来源」，允许即可。
  2. 打开应用，按提示开无障碍
    路径大致是 设置 → 无障碍 → 已下载的服务 → 喵化助手 → 打开。
    不同手机菜单名略有差别：小米在「更多设置」里，华为在「辅助功能」里， OPPO / vivo 在「系统设置」里。
    无障碍必须由你手动打开 —— 这是安卓的规定，任何软件都不能自己给自己开。
  3. 把「生效应用」白名单填上
    在「设置」页填包名，一行一个：
    com.tencent.mobileqq　QQ
    com.tencent.mm　微信
    ★ 白名单空着的话，任何输入框都会被喵化 —— 包括改文件名、填表单、 写搜索框，会很烦也可能误事。建议只填你真正想用的那几个。
  4. 去聊天软件里打字
    打完停一下，它自己就改了（默认停 400 毫秒，可以在设置里调）。
装完发现不生效？把应用从后台划掉重新打开， 再把无障碍「关掉 → 等两秒 → 重新打开」。很多问题这样就解决了 —— 安卓装完新版本后，正在运行的进程还是旧代码。

★ 微信怎么用（重要）

微信能用，但要同时打开一个「读屏服务」。

为什么：微信内部有一份「可信读屏」的名单，只有名单里的服务 （比如系统自带的 TalkBack）才能读取聊天输入框。第三方应用不管申请什么权限、 系统批不批，都不在名单里。这一点我们反复验证过，也拆开微信的安装包确认过 —— 它的代码里直接写着 TalkBack 的包名。所以这不是软件做得不够好，是微信的产品限制。

  1. 确认喵化助手已经开好无障碍
  2. 打开读屏服务：设置 → 无障碍 → TalkBack → 打开
    有些手机自带别的读屏（比如「屏幕朗读」），效果一样，开哪个都行。
  3. 回到微信正常打字，停一下就会喵化
  4. 不用了就把读屏服务关掉
★ 开了读屏之后，手机操作方式会变 —— 这一点必须提前知道，不然会以为手机坏了：
  • 单击 = 选中（只会念一下，不会点下去）
  • 双击 = 真正点击
  • 滑动 = 要用两根手指
也就是说：想点某个东西，先单击它，再双击屏幕任意位置。 如果开着读屏觉得吵，可以在 TalkBack 设置里把语音关掉或调小 —— 它只要「启用着」就行，不一定非得念出来。
怎么确认读屏开没开？喵化助手「设置」页里有一个 「检查微信支持」按钮，点一下它会告诉你当前状态， 没开的话直接带你去无障碍设置。

手机版权限说明

这个 APK 一共只申请 4 个权限：

权限用途会不会弹框
FOREGROUND_SERVICE常驻运行（挂一条通知，别被系统清掉）不会
FOREGROUND_SERVICE_SPECIAL_USE上面那条的用途说明（Android 14 要求）不会
RECEIVE_BOOT_COMPLETED开机自启（只在开关打开时，默认关着）不会
POST_NOTIFICATIONS显示那条常驻通知会，可以拒绝
没有的权限比有的更重要：这个包没有 INTERNET 权限 —— 也就是说它物理上无法联网。就算代码里写了要发数据，系统也不会给它网络。 不是「承诺不联网」，是「根本连不了」。
也没有存储 / 相机 / 麦克风 / 通讯录 / 短信 / 位置 / 悬浮窗。

无障碍不算普通权限 —— 它不在上面那个列表里，必须由你亲自在系统设置里打开， 随时也能关掉。它能做的事被限定得很死：只监听文本变化、焦点、窗口变化等事件， 不截获你的按键。
手机关掉网络也能用。手机版没有「智能语气」（模型太大，而且那需要联网权限）。

七、常见问题

按了没反应？

  • 看右下角托盘图标是不是灰的——灰的代表已暂停，按 Ctrl+Alt+Shift+P 恢复
  • 确认当前窗口程序名在「生效程序」列表里（默认只有 QQ）
  • 确认输入框里有文字——空的时候它什么也不做
  • 看日志（「查看日志」按钮），每一步都有记录

同一句话按两次，会不会越变越长？

不会。程序认得出自己加过的内容，第二次按结果和第一次一模一样（这叫幂等， 开发时专门测过，几十个用例全部通过）。

@ 别人的时候会怎样？

QQ 的 @ 是特殊元素，普通复制粘贴会把它拍平成普通文字、@ 就失效了。 所以当输入框以 @ 开头时，程序会跳过 @ 那一段，只改写后面的内容，@ 原样保留。

改坏了 rules.txt 怎么办？

程序每次写入前都会把上一版存成 rules.txt.bak，直接改名回去就行。 如果某次改动会让内容大幅减少，程序会拦下来不写并弹窗告诉你。

想换回默认风格？

命令行里跑 Miaohua.exe --style 傲娇 就能套用风格，不用点界面。 跑 Miaohua.exe --styles 看全部可选名字。

七之二、更新公告

想知道每个版本改了什么，两个地方都能看：

在哪看
电脑版左边导航最后一项「更新公告」（「关于」旁边）
安卓版「关于」分页里往下翻
两边看的是同一个文件：更新记录.txt。
电脑版是当场读程序旁边那份——你改它、或者以后换了新版本， 界面跟着变，不用重新打包。
安卓版是打包时塞进 APK 的（app 没有联网权限，不可能联网拿）， 每次构建自动同步，不会出现两份内容不一样。

八、它不做什么

  • 不改网址、邮箱、文件路径，以及 #121417 这种给程序读的编号 （2.15.0 起：单独发一个 123 或一串标点也算内容，照样会转换）
  • 不碰代码里的东西，也不碰你没列进「生效程序」的应用
  • 不联网——除非你自己打开「智能语气」，那也只连本机 127.0.0.1
  • 不上传、不保存你输入的内容（只在你自己输入框里原地改写）
  • 不替你点发送——改完还是你自己按回车
