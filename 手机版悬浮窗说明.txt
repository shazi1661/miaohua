  喵化助手 · 手机版「悬浮窗」怎么用
  安卓 3.4.9　·　2026-10-16
════════════════════════════════════════════════════════════════════


★★★  一、这个是干什么的  ★★★

  以前是【自动转换】：你打完字停下来，它自己就把话改了。
  有些人觉得太快 ✗ 想先看看改成什么样再决定 ✓

  悬浮窗就是给这种用法的：

      · 不再自动改
      · 输入框有字的时候冒出一个小圆球
      · 点一下 → 看它打算改成什么
      · 喜欢就点【转换】✗ 不喜欢就点【换一个】✓

  ★ 和电脑版那个【热键转换】是一个意思 ✓


★★★  二、怎么开（两步 ✗ 缺一不可）  ★★★

  ── 第一步：给权限 ──

  打开喵化助手 → 【设置】页 → 往下找

      【授予悬浮窗权限】

  点一下会跳到系统页面 ✗ 找到「喵化助手」✗
  把【允许显示在其他应用上层】打开 ✓

  ★ 这一步必须做 ✗ 不然小球不会出现 ✓
  ★ 不给也不影响其他功能 ✗ 只是没有悬浮球 ✓

  ── 第二步：打开开关 ──

  还在【设置】页 ✗ 找到

      ☑ 悬浮窗（不自动转 ✗ 点一下才转）

  打上勾 ✓ 设置页会告诉你权限给没给 ✓

  ★ 开了悬浮窗就【不会再自动转换】✗ 这是故意的 ✓
  ★ 想回到自动转换 ✗ 把这个勾去掉就行 ✓


★★★  三、怎么用  ★★★

  1. 在 QQ / 微信的聊天框里正常打字
     —— 输入框里【有字】的时候 ✗ 屏幕边上会冒出一个小圆球 ✓
     —— 字清空了 ✗ 小球自己就消失了 ✓

  2. 点一下小圆球 ✗ 展开一个小面板 ✓

         ┌────────────────────────┐
         │ 将要变成：               │
         │ 你好喵~(=^･ω･^=)        │   ← ✗ 这就是预览 ✓
         │                        │
         │ [ 转换 ]    [ 换一个 ]   │
         │        收起             │
         └────────────────────────┘

  3. 看预览 ✗ 满意就点【转换】✗ 它就写进输入框 ✓

  4. 不满意就点【换一个】✗ 它会重新随机一个 ✓
     —— 语气池和颜文字都会重新挑 ✗ 每点一次变一次 ✓
     —— ★ 它每次都从【你打的原话】重来 ✗ 不会越叠越多 ✓

  5. 转换完小球会自己收起来 ✗ 不挡着聊天 ✓

  ★ 【转换】只是写进输入框 ✗ 不会自动发送 ✓
    发送还是你自己点 ✓


★★★  四、小球能拖  ★★★

  按住小球拖到顺手的位置 ✗ 松手就记住 ✓
  下次打开还在那儿 ✓

  ★ 拖的时候不会误触发面板 ✗ 放心拖 ✓


★★★  五、常见问题  ★★★

  ── 小球不出现？──

   ① 确认设置里的【悬浮窗】勾上了
   ② 确认系统里那个【允许显示在其他应用上层】给了
   ③ 确认输入框里【确实有字】（空的本来就不显示 ✓）
   ④ 确认这个应用在【生效列表】里
   ⑤ 换个聊天窗口试试

  ── 点了【转换】没反应？──

   一般是那个输入框不接受程序写入 ✗ 换个聊天软件试试 ✓
   转换成功的话 ✗【我的】页 →【行为日志】里会有
       "悬浮窗写回 [原文] -> [改后]"

  ── 为什么点了【转换】球就没了？──

   故意的 ✗ 写完就收起来 ✗ 免得挡着聊天 ✓
   再打一个字它又出来了 ✓

  ── 想让某个聊天软件不出现小球？──

   把那个应用从【生效列表】里去掉就行 ✓


★★★  六、不想用了  ★★★

  设置页把那行【悬浮窗】的勾去掉 ✗ 立刻恢复成自动转换 ✓
  或者把【授予悬浮窗权限】还回去（系统设置里关掉）✓

  ★ 完全没有任何副作用 ✗ 关了就跟以前一模一样 ✓


★★★  七、隐私  ★★★

  · 悬浮窗只显示【你自己输入框里的内容】✗ 不读别的 ✓
  · 这个版本仍然【没有联网权限】✗ 发不出任何东西 ✓
  · 权限名字叫"显示在其他应用上层"听着吓人 ✗
    实际就是"能在屏幕上画一个小球"✗ 仅此而已 ✓
