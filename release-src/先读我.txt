喵化助手 —— 快速开始
============================================================

【电脑版】

1. 打开「电脑版」文件夹，双击 Miaohua.exe
2. 弹出主界面就是启动成功了。
   点右上角的 X 不会退出程序，只是缩到右下角托盘里
   （看不到图标就点一下任务栏上的 ^ 展开隐藏图标）
3. 在 QQ 里正常打字，按 Ctrl+Shift+M，内容原地变成喵化版
4. 也可以什么都不按：停手约 0.9 秒后自动转换

   三个快捷键：
     Ctrl+Shift+M        立即转换当前输入框
     Ctrl+Alt+Shift+P    暂停 / 恢复
     Ctrl+Alt+Shift+R    改完规则后重新加载

   想真正退出：右键托盘图标 → 退出


【安卓版】

1. 把「安卓版\Miaohua.apk」传到手机安装
   （会提示「未知来源应用」，允许即可。这是自签名包，必然有这个提示）
2. 打开「喵化助手」，点「去开启无障碍服务」
3. 在「已下载的服务」里找到「喵化助手」并打开它
4. 之后在 QQ 里打字，停手约 0.7 秒自动喵化

   不想用了：系统设置 → 无障碍 里关掉，或直接卸载


【改规则】

电脑版：主界面「规则」页直接改，点「保存规则」，立即生效
安卓版：App 里改，点「保存规则」

规则里的参数名中英文都认，比如「颜文字」和「kaomoji」是同一个设置。
两边格式完全一样，电脑版改好的规则可以直接复制到安卓版用。

详细的规则说明、换图标换配色、常见问题，都在「使用说明.md」里。


【需要知道的事】

· 安卓版没有申请任何权限——连联网权限都没有，所有处理都在手机上完成，
  文字不会离开设备。它也只在你规则里列出的应用（默认只有 QQ）里生效。
· 电脑版同样全部本地处理，不联网。
· 电脑版默认只在 QQ 里自动转换；想加微信，在规则里加一行：程序 = Weixin
· 转换会改写整个输入框，完成后光标跳到文字结尾。
· 如果 Windows 弹出蓝色窗口说「已保护你的电脑」，那是**未签名程序的正常提示**
  （代码签名证书要花钱买），点「更多信息」→「仍要运行」就行。
· 电脑版需要 .NET Framework 4.5 以上，Win10 / Win11 都自带，不用额外装。
