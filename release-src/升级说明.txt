喵化助手 · 这个包怎么用
================================================

这个包（无模型版）里面是**完整的程序**，只有一样东西没带：
本机 AI 模型（2 GB 的那个）。它有两种用法，都合法：

────────────────────────────────────────────────
用法一：给别人试用
────────────────────────────────────────────────
直接发这个包就行，才几百 KB。

  解压 → 打开「电脑版\Miaohua.exe」→ 就能用

【全部功能都在】
  · 文字替换成喵喵的规则         ✓
  · 句尾颜文字、语气词           ✓
  · 萌系 / 元气 / 慵懒 / 撒娇 / 冷淡 / 颜文字在前   ✓
  · 傲娇 / 黏人 / 慵懒 / 委屈 / 元气 / 应激 语气改写  ✓
  · 自动转换、快捷键、只对 QQ 生效  ✓
  · 安卓版（安卓版\Miaohua.apk）   ✓ 零权限

【只有一样会差一点】
  「智能语气」本该用本机 AI 判断情绪，这里没有模型，
  就自动改用关键字判断。

      大部分句子结果一样，
      否定句会判错 ——「我不难过」可能被判成难过。

  介意的话，在「设置」里关掉「开启智能语气」即可，
  其余功能完全不受影响。这一点也不影响速度，不会卡。

────────────────────────────────────────────────
用法二：给已经装过的人升级
────────────────────────────────────────────────
解压出来，覆盖到原来那个文件夹就行：

  1. 解压这个压缩包，里面只有一个「喵化助手」文件夹
  2. 把「喵化助手」拖到你已经装好的那个「喵化助手」文件夹上面
     （或解压时把目标选成原来那个文件夹的上一层）
  3. Windows 问「是否替换这些文件」—— 选「替换」

【重点】模型不会被动到。
  电脑版\模型\ 里那 2 GB 的文件原样保留，不用重新下。

────────────────────────────────────────────────
想让 AI 真的生效
────────────────────────────────────────────────
两条路，任选：

  A. 用文件名带「自带模型」的那个包（约 2 GB）
     里面有模型和推理程序，程序会自己把它拉起来。
     第一次启动等 7~10 秒，之后每次也是这个时间。
     占 2 GB 磁盘、运行时约 3.4 GB 内存。

  B. 自己装一个本地模型服务（LM Studio 或 Ollama），
     然后在「设置」里填地址：
         LM Studio : http://127.0.0.1:1234
         Ollama    : http://127.0.0.1:11434
     模型名填服务器上那个（Ollama 是 qwen2.5:3b 这种）。

【怎么确认生效了】
  打开程序 → 左侧「设置」→ 看「智能语气」下面的状态行：
      模型服务在运行 ✓     → 正常，否定句也能判对
      模型服务没在跑 ✗     → 正在用关键字判断，功能照常
