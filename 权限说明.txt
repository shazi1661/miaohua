喵化助手 · 权限说明
（可以照着念 / 直接贴出去）

════════════════════════════════════════════════════════════
一、这个 APK 里一共只有 4 个权限
════════════════════════════════════════════════════════════

  1. FOREGROUND_SERVICE
     「允许它挂一条常驻通知跑在后台」
     这是"常驻运行"用的，属于普通权限，安装时就给，不会弹框。

  2. FOREGROUND_SERVICE_SPECIAL_USE
     上面那条的补充说明，Android 14 开始要求写清楚用途。
     同样是普通权限，不弹框。

  3. RECEIVE_BOOT_COMPLETED
     「开机后自动启动」
     只有你打开「常驻运行」开关时才会用到。普通权限，不弹框。

  4. POST_NOTIFICATIONS
     「允许它显示通知」
     ★ 这是唯一一个会弹系统询问的 ★ 你可以拒绝。
     拒绝了软件照样用，只是那条"待命中"的通知看不见。

════════════════════════════════════════════════════════════
二、★ 没有的权限，比有的更重要 ★
════════════════════════════════════════════════════════════

  ✗ 没有 INTERNET —— ★ 这个包物理上无法联网 ★
     就算代码里写了要发数据，系统也不会给它网络。
     这是最硬的一条：不是"承诺不联网"，是"根本连不了"。

  ✗ 没有 存储 / 读取文件
  ✗ 没有 相机
  ✗ 没有 麦克风
  ✗ 没有 通讯录 / 短信 / 通话记录
  ✗ 没有 位置
  ✗ 没有 读取已安装应用列表
  ✗ 没有 悬浮窗
  ✗ 没有 修改系统设置

  对照一下：Chrome 和 QQ 各自声明了几十个权限。
     喵化助手：4 个。

════════════════════════════════════════════════════════════
三、无障碍权限是怎么回事
════════════════════════════════════════════════════════════

  它【不在】上面那个权限列表里 —— 无障碍不是普通权限，
  它必须由你亲自在系统设置里打开：

      设置 → 无障碍 → 已下载的服务 → 喵化助手

  而且它能做的事被限定得很死（这些写在应用的配置文件里）：

      · 只监听一种事件：文本变化（typeViewTextChanged）
        别的（点击、滚动、窗口切换……）它一概收不到
      · 反馈类型：generic
      · 不请求 flagRequestFilterKeyEvents（不截获你的按键）
      · 不请求 flagRetrieveInteractiveWindows 之外的窗口能力

  随时可以关：同一个页面关掉开关，软件立刻失效。

════════════════════════════════════════════════════════════
四、电脑版的情况（含"断网能不能用"）
════════════════════════════════════════════════════════════

  电脑版默认【完全不联网】。断网也能完整使用。

  只有你主动打开「智能语气」时，它才会发起网络请求 —— 而且只往
  「模型地址」那一栏填的地址发。默认填的是 127.0.0.1，
  也就是你自己这台电脑上的模型服务（LM Studio / Ollama 之类）。

  ★ 这里要如实说一句：那一栏是【可以改的】★
     如果你想连局域网上另一台机器上的模型，填它的地址就行 ——
     那时它当然会连那台机器。默认值是本机，不是"写死了不许联网"。
     想彻底一次请求都不发：把「智能语气」关掉即可。

  ★★ 但要说清楚：这不等于"开了智能语气就得联网" ★★

  127.0.0.1 是操作系统【内部的回环接口】—— 不经过网卡、不经过路由器、
  不经过任何网络设备。拔网线、关路由器、开飞行模式，对它毫无影响。

  所以：只要「模型地址」保持默认的 127.0.0.1，
        开不开智能语气都【照样能断网使用】。

  而且「自带模型」那个安装包里直接带了模型和运行时
  （qwen2.5-3b-instruct-q4_k_m.gguf + llama.cpp），
  连 LM Studio 都不用装 —— 程序会自己把它跑起来，全程在本机。

  就算模型没能启动也不会出错：会静默退回关键词判断，
  照旧能用，只是情绪判断粗一点。日志里会写一行说明。

  只有当【你把那一栏改成别的机器的地址】时，它才真的需要那个地址可达。

  整个程序里只有 2 处发起网络请求，都是这一件事（问模型"这句是什么情绪"）。
  没有更新检查，没有统计上报，没有任何"偷偷回传"。

  它做的事只有两件：
      · 装一个全局键盘钩子（用来知道你在打字、以及注册快捷键）
      · 发模拟按键（Ctrl+A / Ctrl+C / Ctrl+V）来读写那个输入框

  ★ 注意：正因为有这两件事，【绝对不要往网游里用】★
     反作弊会把"全局钩子 + 模拟按键"判定成外挂。

════════════════════════════════════════════════════════════
五、自己验证的办法
════════════════════════════════════════════════════════════

  手机装完在系统设置里看：
      设置 → 应用 → 喵化助手 → 权限
  应该只看到"通知"这一项能开关。

  或者用 adb（给会的人）：
      adb shell dumpsys package com.miaohua.helper | findstr uses-permission
  只会列出上面那 4 条，没有 INTERNET。

════════════════════════════════════════════════════════════
六、已知用不了的地方（说清楚，免得白折腾）
════════════════════════════════════════════════════════════

  ✗ 游戏（Unity / UE 那类）
    画面是引擎自己画的，无障碍树里只有一整块画布，没有可读写的控件。

  △ 微信的聊天输入框（能用 —— 但要同时开一个读屏服务）

    原因：微信只在系统【有读屏服务在运行】的时候，才把输入框交给无障碍服务。

    ★ 实测确认过的三件事：
       · 单独开喵化助手             → 读不到 ✗
       · 喵化助手 + TalkBack 同时开  → ★ 微信正常替换 ✓
       · 应用自己请求「触摸探索模式」 → 系统不采纳 ✗
         （3.4.2 试过：连自己画的焦点高亮框都一次没出现过，
           说明那个模式根本没被真正启用。这一步只能由
           【系统签名的读屏应用】完成，普通应用做不到。）

    ★ 所以用法是：
       用微信时，同时打开任意一个读屏服务（比如系统自带的 TalkBack）。
       平时关掉，不影响日常操作。

    ★ 应用「设置」页有一个「检查微信支持」按钮：
       点一下会检测系统里有没有【别的】读屏服务在跑；
       没有的话，直接带你去无障碍设置。

    ★ 注意：读屏服务开着的时候，操作方式会变 ——
       单击是「选中」（只会念一下）、双击才是「点击」，滚动要用两根手指。
      这一点必须提前知道，不然会以为手机坏了。
