【必须先做的】

① ★ 那 2GB 的模型文件绝对不能进仓库 ★
   GitHub 单文件上限 100MB，硬推会被拒。
   已经写进 .gitignore 了：*.gguf / 模型/ / 模型运行时/
   想给用户就放 Release 附件，或者让他们从 HuggingFace 自己下。

② ★ .exe / .apk / .zip 也排除掉（已写进 .gitignore）★
   这些走 Release 附件更合适。
   Release 里挂：
       喵化助手_PC2.15.0_安卓3.4.2_无模型版_20261006.zip
       喵化助手_安卓版_v3.4.2.apk
       更新记录.txt

③ ★ 检查有没有硬编码的绝对路径 ★
   构建脚本里有 D:\harness gzq\009\... 这种路径 —— 自己用没事，
   别人 clone 下来要改。
   ★ 建议：在脚本顶部集中成一个变量，注释里写"改成你的路径"。

④ ★ 别忘了 LICENSE ★
   见下面"许可怎么选"。

⑤ ★ 把规则文件里的个人信息看一眼 ★
   rules.txt 里的规则是你自己配的 —— 确认没有不想公开的东西。

【许可怎么选】

   选项 A：MIT
       最省事，别人能随便用、随便改、甚至能拿去卖。
       ★ 和你在「关于」页写的"完全免费、别买"是【冲突】的 ★
         因为 MIT 允许别人卖。

   选项 B：MIT + 附加条款（推荐）
       保留 MIT 的自由度，但加一句：
       "本软件免费提供。禁止以任何形式倒卖本软件或其修改版。"
       —— 这不是标准 OSI 许可，但表达了你的意图。

   选项 C：GPL-3.0
       别人改了必须也开源。
       如果你在意"改进了不还回来"，选这个。

   ★ 我的建议：B。你的核心诉求是"免费、别被拿去卖"，
     MIT 单独用达不到这个效果。

【README 里建议保留的几段】

   · 权限说明（尤其是"没有 INTERNET，物理上无法联网"）
   · 已知用不了的地方（游戏 / 自绘编辑器）
   · 安卓微信要配读屏服务才能用（这条容易被误读成"不支持"，写清楚）
   · 电脑版的封号风险提醒（网游里别用）
   · 完全的免费声明
   —— 这几段既是给用户看的，也是给人挑刺时挡在前面的。

【可以先不做的】

   · CI / 自动构建（手工构建链够用）
   · 单元测试（引擎的回归测试脚本在 check-engines.ps1 里，可以先留着）
