────────────────────────────────────────────────────────────────────
  一、这是什么
────────────────────────────────────────────────────────────────────

一个本地运行的小工具：在聊天框里打完字，停一下，整段文字就变成
喵喵的语气，句尾还会加一个随机颜文字。

  例如：

      输入：  你好
      输出：  你好喵~(=^･ω･^=)

      输入：  今天天气不错，我们出去玩吧
      输出：  今天天气不错喵~，我们出去玩吧喵~ ฅ^•ﻌ•^ฅ

【它不会做什么】
  · 不上传、不保存你输入的内容（只在你自己的输入框里原地改写）
  · 不碰网址、邮箱、文件路径和含数字的编号（怕改坏订单号、验证码之类）
  · 默认不联网


────────────────────────────────────────────────────────────────────
  二、安卓版怎么装
────────────────────────────────────────────────────────────────────

  1. 把 APK 传到手机上（微信传、数据线传都行）
  2. 点开它 → 系统可能提示"未知来源"，允许即可
  3. 装完打开应用
  4. 按应用里的提示开无障碍：

         设置 → 无障碍 → 已下载的服务 → 喵化助手 → 打开

     不同手机菜单名可能略有差别：
         小米：设置 → 更多设置 → 无障碍
         华为：设置 → 辅助功能 → 无障碍
         OPPO/vivo：设置 → 系统设置 → 无障碍

  ★ 无障碍必须由你【手动】打开 —— 这是安卓的规定，
    任何软件都不能自己给自己开。

  ★ 如果装完发现不生效：把应用从后台划掉，重新打开，
    再把无障碍【关掉 → 等两秒 → 重新打开】。很多问题这样就解决了。


────────────────────────────────────────────────────────────────────
  三、怎么用
────────────────────────────────────────────────────────────────────

  「试一下」页   —— 先在这里试，不用切来切去。下面有个行为日志，
                    出问题的时候看它。

  「风格」页     —— 选外观风格和语气。左边那栏只管句尾，
                    右边那栏会连开头结尾一起改。

  「规则」页     —— 写你自己的替换规则。格式很简单：
                        原文 => 替换成
                    一行一条。

  「设置」页     —— 生效应用（白名单）、停手多久、常驻运行、
                    微信支持检查。

【怎么触发】
  打完字停一下，它自己就会改。停多久算"停"可以在设置里调，
  默认 400 毫秒。

【★ 白名单很重要 —— 建议一开始就填上】
  在「设置」页的"生效应用"里填包名，一行一个。例如：

      com.tencent.mobileqq           QQ
      com.tencent.mm                 微信

  ★ 白名单【空着】的话，任何输入框都会被喵化 ——
    包括改文件名、填表单、写搜索框，会很烦，也可能误事。
    建议只填你真正想用的那几个。


────────────────────────────────────────────────────────────────────
  四、★ 微信怎么用（重要）
────────────────────────────────────────────────────────────────────

  微信能用，但要同时打开一个"读屏服务"。下面是原因和步骤。

【为什么】
  微信内部有一份"可信读屏"的名单，只有名单里的服务
  （比如系统自带的 TalkBack）才能读取聊天输入框。
  第三方应用不管申请什么权限、系统批不批，都不在名单里。

  这一点我们反复验证过，也拆开微信的安装包确认过 ——
  它的代码里直接写着 TalkBack 的包名。
  所以这不是软件做得不够好，是微信的产品限制。

【步骤】
  1. 确认喵化助手已经开好无障碍
  2. 打开读屏服务：

         设置 → 无障碍 → TalkBack → 打开

     有些手机自带别的读屏（比如"屏幕朗读"），效果一样，开哪个都行。
  3. 回到微信，正常打字 → 停一下 → 就会喵化了
  4. ★ 不用了就把读屏服务关掉

【★ 开了读屏之后，手机操作方式会变】
  这一点必须提前知道，不然会以为手机坏了：

      单击  = 选中（只会念一下，不会点下去）
      双击  = 真正点击
      滑动  = 要用【两根手指】

  也就是说：想点某个东西，先单击它，再双击屏幕任意位置。

【怎么确认读屏开没开】
  应用「设置」页有一个「检查微信支持」按钮，
  点一下它会告诉你当前状态，没开的话直接带你去设置。

【开着读屏会不会很吵】
  可以在 TalkBack 设置里把语音关掉或调小 —— 它只要"启用着"就行，
  不一定非得念出来。

────────────────────────────────────────────────────────────────────
  六、权限说明
────────────────────────────────────────────────────────────────────

【安卓版一共只申请 4 个权限】

  FOREGROUND_SERVICE             常驻运行（挂一条通知，别被系统清掉）
  FOREGROUND_SERVICE_SPECIAL_USE 上面那条的用途说明（Android 14 要求）
  RECEIVE_BOOT_COMPLETED         开机自启（只在开关打开时，默认关着）
  POST_NOTIFICATIONS             显示那条常驻通知（唯一会弹框问你的）

【没有的权限比有的更重要】

  ✗ 没有 INTERNET
    这个包【物理上无法联网】。就算代码里写了要发数据，
    系统也不会给它网络。不是"承诺不联网"，是"根本连不了"。

  ✗ 没有存储 / 相机 / 麦克风 / 通讯录 / 短信 / 位置 / 悬浮窗

【关于无障碍】

  它不在上面那个权限列表里 —— 无障碍不是普通权限，
  必须由你亲自在系统设置里打开，随时也能关掉。

  它能做的事被限定得很死：只监听文本变化、焦点、窗口变化等事件，
  不截获你的按键。

【电脑版】

  默认完全不联网。只有你打开「智能语气」时才会连你自己填的模型地址
  （默认是本机 127.0.0.1，也就是你自己这台电脑）。
  没有更新检查，没有统计上报。


────────────────────────────────────────────────────────────────────
  七、常见问题
────────────────────────────────────────────────────────────────────

  Q：打完字没反应？
  A：按顺序检查 ——
     ① 无障碍开了吗（设置 → 无障碍 → 喵化助手）
     ② 这个应用在"生效应用"白名单里吗
     ③ 「试一下」页下面有行为日志，看它写了什么
     ④ 把无障碍关掉再打开一次

  Q：微信里为什么不行？
  A：看第四节 —— 要同时开一个读屏服务。

  Q：会不会上传我的聊天记录？
  A：不会。安卓版没有网络权限，物理上做不到。
     电脑版默认也不联网，只有你主动开「智能语气」时才会连
     你自己填的那个地址。

  Q：游戏里能用吗？
  A：不能。游戏画面是引擎自己画的，系统里没有可操作的输入框。

  Q：电脑版会被封号吗？
  A：★ 千万不要在网游里用电脑版。
     它用的是"全局键盘钩子 + 模拟按键"，反作弊会判定成外挂，
     有封号风险。单机游戏、聊天软件、办公软件都没问题。

  Q：怎么彻底关掉？
  A：设置 → 无障碍 → 喵化助手 → 关掉。关掉之后它什么也做不了。

  Q：手机里那个"单击变成选中"是怎么回事？
  A：你开着读屏服务（比如 TalkBack）。不用了关掉就恢复正常。


────────────────────────────────────────────────────────────────────
  八、电脑版
────────────────────────────────────────────────────────────────────

  · 解压后双击 喵化助手.exe 就能用，不需要安装
  · 默认快捷键 Ctrl+Alt+Shift+M，把当前输入框里的内容喵化
  · 「智能语气」是可选功能：用你自己电脑上的模型判断情绪，
    比关键词准得多。不用它也能完整使用（会自动退回关键词判断）
  · 规则文件是 rules.txt，记事本就能编辑

  ★ 再说一次：不要在网游里用。
