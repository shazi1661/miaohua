# ---------------- 条件替换（看情况才换）----------------
#
# 上面那些写法是【无条件】的 ✧ 只要出现就换 ✓
# 下面这种写法可以【满足条件才换】✧ 能看懂上下文 ✓
#
# 格式：
#     如果 <条件> 就将 <原文> 替换成 <换成什么>
#
# 多个条件用【，】隔开 ✧ 全部满足才生效 ✓
#
# 支持这些条件：
#     含"某某"        整句里有这几个字
#     不含"某某"      整句里没有
#     前有"某某"      紧挨在前面
#     后有"某某"      紧挨在后面
#     在句首          这个词在开头
#     在句尾          在结尾
#     整句是"某某"    整句就等于它
#     长度>=5         字数条件（>= <= > < = 都行 ✓）
#     上文含"某某"      聊天上下文（对方最近说的）里有这几个字
#     上文不含"某某"    上下文里没有
#
# ★ 这两个要【看聊天记录】✗ 和上面那七种不一样 ✓
#
#   例子：
#       如果 上文含"考砸" 就将 没事的 替换成 没事的啦
#       如果 上文含"谢谢" 就将 不客气 替换成 不用谢
#       如果 上文不含"晚安" 就将 好 替换成 好呀
#
# ★ 读不到聊天记录时 ✗ 这两条【都不会生效】✗ 不会乱换 ✓
#   （读不到的情况：没开 QQ/微信 ✗ 用的不是这两个 ✗ 界面变了 ✓）
#   —— ★ 宁可不动 ✗ 也不猜错 ✓
#
# ★ 电脑版怎么读：
#     开着 QQ / 微信 ✗ 转换时自动看一眼当前聊天窗口的最近几条 ✓
#     条数由【上下文条数】控制 ✗ 默认 8 条 ✓
#     读完缓存 1.5 秒 ✗ 连续打字不会卡 ✓
#
# ★ 想验证规则写得对不对 ✗ 命令行可以注入一段假上下文：
#     Miaohua.exe --ctx "对方：我今天考砸了" --trace "没事的"
#   —— ★ 应该输出「没事的啦…」✗ 换成别的上下文就不该变 ✓
#

#     语气=疑问       语气判断（开心/难过/生气/疑问/普通 ✓）
