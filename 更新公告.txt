  2.17.0 / 3.6.0　·　2026-10-31
════════════════════════════════════════════════

  ★ 新功能：大模型改写语气
      【开头 / 后缀 / 颜文字 / 结尾】四段都可以由模型现场写
      （设置里的「AI 写开头结尾」模式，现在是四段全写）
      不用规则拼装了 —— 直接把整句交给模型，让它用这个语气重写一遍。
      支持任何 OpenAI 兼容接口（DeepSeek / OpenAI / LM Studio / Ollama / 本地 llama-server）

    · 四种模式（rules.txt 里的「改写模式」）
        off     不用（默认，还是老样子）
        manual  只在手动转换时用
        auto    自动转换也用它（安卓会直接写回输入框）
        wrap    只让模型生成「句首 + 句尾」，装饰还是规则做（省 token）

    · 电脑版：设置页最下面新增「大模型改写」一段
        模式按钮 ✗ 接口地址 ✗ 模型名 ✗ 密钥 ✗ 试一下
    · 安卓版：暂时要在「喵化规则」页里手写这几行（下个版本补设置界面）
        改写模式 = manual
        改写地址 = https://api.deepseek.com
        改写模型 = deepseek-chat
        改写密钥 = sk-xxxx
    · 失败了（超时 / 报错 / 胡说八道）自动退回规则结果，不会卡住
    · 预览里不调接口（不然打字会卡）

      收起 130ms 淡出再移除；球和小尾巴也是淡入
