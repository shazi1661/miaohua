■■■ 一、这个软件是干什么的 ■■■

在聊天的时候，把输入框里正在打的字【变成喵化的样子】。

  你打完字 → 按快捷键（或停顿一下）→ 文字变成：
    你好呀  →  你好呀喵~ (｡･ω･｡)
             →  （换一个风格后）哼，你好呀……才不是想理你呢，喵！(￣^￣)

—— 免费 ✗ 不联网 ✗ 不上传 ✗ 两个平台都有

一个人做的 ✗ 发给 QQ 群友用 ✗ 现在大概几百个用户


■■■ 二、技术底子（限制条件，很重要）■■■

【电脑版】
  语言      C# 5（.NET Framework 4.8）✗ 语法很老 ✗ 不能用 out var / 模式匹配
  界面      WinForms ✗ 全部自己画 ✗ 没有 WPF
  编译      用 Windows 自带的 csc.exe ✗ 不装 Visual Studio
  体积      单文件 exe 约 600 KB
  输入捕获  低级键盘钩子（WH_KEYBOARD_LL）
  取文字     UI Automation（读别的进程的编辑框）
  写文字     模拟 Ctrl+V 粘贴

【安卓版】
  语言      Java 8 ✗ 无 Kotlin
  输入捕获  AccessibilityService（无障碍服务）
  体积      apk 约 1.9 MB
  构建      自己写脚本调 javac / d8 / aapt2 ✗ 不用 Android Studio
  注意      d8 8.2.2 处理不了匿名内部类 ✗ 所有监听器必须写成具名静态类

【两端共同】
  两套独立引擎（C# 一套 / Java 一套）✗ 改完要跑对拍脚本
  没有服务器 ✗ 没有账号 ✗ 没有云同步
  安卓版连 INTERNET 权限都没有 ✗ 物理上无法联网


■■■ 三、已有的功能（完整列表）■■■

────────────── 3.1 输入与转换 ──────────────

【两种触发方式】
  · 快捷键转换：电脑 Ctrl+Shift+M ✗ 安卓点悬浮球
  · 自动模式：停止打字 N 毫秒后自动转换（可调 200~2000 ms）

【三种转换强度】
  · 轻度：只加句尾
  · 中度：句尾 + 颜文字
  · 重度：再加语气改写

【就地转换】
  · 电脑：读出你输入框里的文字 → 改 → 用 Ctrl+V 粘回去
    光标位置保留 ✗ 撤销堆栈可用 ✓
  · 安卓：通过无障碍服务 ACTION_SET_TEXT 写回

【防误触】
  · 打拼音时不会被中途打断（两端都修过）
  · 刚撤销过的话 5 秒内不自动转换

────────────── 3.2 风格系统 ──────────────

【外观风格 15 个】（管句尾和颜文字）
  萌系 / 元气 / 慵懒 / 撒娇 / 冷淡 / 温柔 / 害羞 / 中二
  天然呆 / 毒舌 / 口癖 / 病娇 / 热血 / 颜文字在前 / 只有喵~

  —— 每个自带 25 个颜文字 ✗ 句尾后缀各不相同
  —— 「只有喵~」是特意做的 ✗ 不加任何颜文字 ✓

【语气风格 14 个】（管整句话怎么说）
  傲娇 / 黏人 / 慵懒 / 委屈 / 元气 / 应激 / 温柔 / 高冷
  中二 / 天然呆 / 毒舌 / 病娇 / 热血 / 腹黑

  —— 每个 178~243 条台词 ✗ 分散在 21 类场景池里
     （通用 / 疑问 / 感叹 / 请求 / 拒绝 / 道歉 / 感谢 / 恭喜 /
       邀请 / 惊讶 / 害怕 / 疲惫 / 无聊 / 失望 / 安慰 / 打招呼 / 再见 …）
  —— 每个另有「开头」36~39 条 ✗ 「结尾」36~39 条
  —— 「应激」是按心理应激四类反应写的（情绪/生理/认知/行为）
     还加了猫的哈气行为：（哈气）（呲牙）（低吼）（尾巴炸开）哈—— 嘶——！

【风格叠加】
  · 外观 + 语气可以同时用
  · 例：外观「撒娇」+ 语气「傲娇」= 句尾撒娇 ✗ 整句像傲娇 ✓

【自定义风格】（2.16.0 新增）
  · 电脑：风格页 →「+ 新建」/「+ 新建语气」
      存进 style-custom.txt / tone-custom.txt（纯文本，能手改）
      右键自己建的那个 → 删除
  · 安卓：风格页底部 →「+ 新建外观」/「+ 新建语气」
      存在规则文件里：自定义外观 = 名字|后缀|颜文字
                     自定义语气 = 名字|后缀|颜文字|开头|结尾

【按软件 / 按包名分配风格】（2.16.0 新增）
  · 电脑：设置页 →「按软件分配…」→ 弹窗里配
      或者写 进程风格 = QQ.exe = 傲娇
  · 安卓：写 包名风格 = com.tencent.mobileqq = 傲娇
  · 「不加」= 在那个软件里完全不喵化

────────────── 3.4 智能语气（可选）─────────────

【两个模型，两回事】

  小模型 clf.bin    6.5 MB    自己写的 13 类分类器
     —— 电脑 C# 实现 + 安卓 Java 实现 ✗ 两端对拍 17/17 一致
     —— 毫秒级 ✗ 不占内存 ✗ 随程序带
     —— 13 类：普通 / 疑问 / 感叹 / 开心 / 喜爱 / 生气 / 难过 …

  大模型 *.gguf     2~4 GB    llama.cpp 跑的语言模型
     —— 只判断情绪（回一个词）✗ 不用它生成文字
     —— 输出：开心 / 生气 / 难过 / 着急 / 惊讶 / 害羞 / 平静
     —— 用户自己下 ✗ 丢进「模型」文件夹就自动认 ✓
     —— 放几个认几个 ✗ 「模型」按钮弹列表选 ✓

【没有模型也能用】
  · 自动退回关键词判断 ✗ 只有否定句（「我不生气」）会判错
  · 全程不出这台机器 ✗ 安卓版连联网权限都没有

【读聊天上下文】（电脑版）
  · 用 UI Automation 读屏幕上最近 8 条消息
  · 判断你的情绪时可以带上上下文

■■■ 四、已经想做但【没做】的（别重复建议）■■■

【做不了的】—— 这些在当前技术栈下做不了，别再建议
  ✗ 游戏里用（DirectX 全屏 ✗ 钩子拿不到）
  ✗ MT 管理器那种自绘编辑器（读不出文字）
  ✗ 安卓微信（有些版本要同时开读屏服务才能读，不可靠）
  ✗ 云端同步 / 多设备（没有服务器 ✗ 也不想加）
  ✗ 语音 / 音效（会让包变大 ✗ 而且核心是文字）
  ✗ 用 AI 直接生成回复内容（他只想要「改装饰」✗ 不想代聊）

【想过但没做的】
  ✗ 表情包 / 图片输出
  ✗ 更多平台（iOS ✗ macOS ✗ Linux）
  ✗ 插件市场 / 共享风格
  ✗ 皮肤系统（现在只有一套粉色）
  ✗ 桌面宠物 / 桌面挂件
  ✗ 聊天记录分析（读历史消息统计情绪）
  ✗ 定时 / 场景模式（上班用冷淡 ✗ 下班用撒娇）
  ✗ 语音朗读喵化后的句子
  ✗ 更多语言的风格（日语 / 韩语的「可爱语尾」）

【用户已经明确拒绝的方向】
  ✗ 别做太大的东西（一个人维护 ✗ 越简单越好）
  ✗ 别塞广告 / 别收费
  ✗ 别加联网（安卓连权限都没有）


■■■ 五、现在的痛点（如果 AI 问「哪里不爽」）■■■

  ① 颜文字还是会重复（92 个抽多了就看出来）
  ② 语气风格有时候「不对劲」——同一句话两次结果差很多
  ③ 自动模式的时机不好调（太快打断 ✗ 太慢没感觉）
  ④ 电脑版在浏览器里有时候取不到输入框
  ⑤ 安卓版要手动重开无障碍服务（每次装新版本都得重开）
  ⑥ 风格太多了 ✗ 选不过来 ✗ 没有「收藏几个常用组合」
  ⑦ 没有「这一次换一个」的快捷方式（只能整体换风格）


■■■ 六、问 AI 的时候可以这样问 ■■■

  「这是一个把聊天文字变成喵化样子的小工具，两端已经做了上面这些功能。
    基于这些已有的东西，你觉得还能加什么？
    请考虑：一个人维护、不能联网、不能装大依赖、两端都要能做的优先。」
