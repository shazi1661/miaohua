# 喵化助手

一个本地运行的小工具：在聊天框里打完字，停一下，整段文字就变成喵喵的语气，
句尾还会加一个随机颜文字。

电脑版（Windows）和安卓版都有。**完全免费，没有联网功能。**

**界面有中文和英文两套**，左下角按钮一点就换 —— 规则、风格、颜文字整套跟着走。

---

## 它能做什么

- **词语替换** —— 规则里写 `原文 => 替换成`，从上到下依次执行
- **句尾装饰** —— 每个句子后面加后缀和随机颜文字
- **三种程度** —— 轻度（只加一次）/ 普通（每句）/ 重度（连逗号）
- **两套风格** —— 外观风格只改句尾；语气改写会在句首句尾加话
- **语气跟着情绪变** —— 疑问 / 开心 / 难过 / 生气 / 普通 各走各的词库
- **智能语气（可选）** —— 用你自己电脑上的模型判断情绪，比关键词准得多
- **两种触发** —— 全局快捷键，或停止打字后自动转换
- **中英双语** —— 界面、规则、风格、颜文字整套切换
- **数字和标点也算内容** —— 只发一个 `123` 或一串标点，照样转换

## 大模型改写（2.17.0 新增，默认关闭）

除了规则拼装，还可以把整句交给大模型，让它用这个语气重写一遍。
支持任何 **OpenAI 兼容**接口（DeepSeek / OpenAI / LM Studio / Ollama / 本地 llama-server）。

| `改写模式` | 行为 |
|---|---|
| `off` | 不用模型，只有规则（**默认**） |
| `manual` | 只在按快捷键时用，自动转换仍走规则（推荐） |
| `auto` | 自动转换也用（会等 1~2 秒） |
| `wrap` | 只让模型写包装：开头 / 后缀 / 颜文字 / 结尾四段，正文不动 |

**要先自己填接口地址和密钥**（仓库里只有空白的 `pc/rules-sample.txt`，真实密钥不会提交）：

```
改写模式 = manual
改写地址 = https://api.deepseek.com
改写模型 = deepseek-chat
改写密钥 = sk-你的密钥
```

密钥只存本机 `rules.txt`。失败（超时 / 报错 / 回复离谱）会自动退回规则结果。

> ⚠️ **安卓版不提供这个功能。** 安卓包刻意没有 `INTERNET` 权限（见下面「它不会做什么」）——
> 保住「物理上无法联网」比接大模型更重要。3.6.1 起已把安卓端相关代码移除。

## 它不会做什么

- **默认不联网**。断网也能完整使用。
- 只有两种情况会发起请求，而且地址都是你自己填的：
  1. 打开「智能语气」时问模型这句话什么情绪（默认 `127.0.0.1`，就是你自己这台电脑）
  2. 打开「大模型改写」时把句子发给模型（**默认关闭**，不填地址就不会发）
- **没有更新检查，没有统计上报，不上传任何结果。**
- 不上传、不保存你输入的内容（只在你自己的输入框里原地改写）
- 不碰网址、邮箱、文件路径，以及 `#121417` 这种给程序读的编号

## 权限

### 安卓版

APK 里一共只有 4 个权限：

| 权限 | 用途 | 会不会弹框 |
|---|---|---|
| `FOREGROUND_SERVICE` | 常驻运行（挂一条通知，别让系统清掉） | 不会 |
| `FOREGROUND_SERVICE_SPECIAL_USE` | 上面那条的用途说明（Android 14 要求） | 不会 |
| `RECEIVE_BOOT_COMPLETED` | 开机自启（只在开关打开时） | 不会 |
| `POST_NOTIFICATIONS` | 显示那条常驻通知 | **会，可以拒绝** |

**没有的权限比有的更重要：**

- ✗ **没有 `INTERNET`** —— 这个包**物理上无法联网**。就算代码里写了要发数据，
  系统也不会给它网络。不是"承诺不联网"，是"根本连不了"。
- ✗ 没有存储 / 相机 / 麦克风 / 通讯录 / 短信 / 位置 / 读取已应用列表 / 悬浮窗

### 无障碍权限

它**不在**上面那个权限列表里 —— 无障碍不是普通权限，必须由你亲自在
系统设置里打开：`设置 → 无障碍 → 已下载的服务 → 喵化助手`。

它能做的事被限定得很死（写在 `res/xml/accessibility_service_config.xml` 里）：

- 只监听文本变化、焦点、窗口变化等事件 —— 不截获你的按键
- 不请求 `flagRequestFilterKeyEvents`
- 随时可以关，关上立刻失效

### 电脑版

默认完全不联网。只有打开「智能语气」时才会连你填的那个地址（默认本机）。

它做的事只有两件：装一个全局键盘钩子（知道你在打字 + 注册快捷键），
发模拟按键（`Ctrl+A` / `Ctrl+C` / `Ctrl+V`）来读写那个输入框。

> ⚠️ **正因为有这两件事，绝对不要往网游里用。**
> 反作弊会把"全局钩子 + 模拟按键"判定成外挂，有封号风险。

## 已知用不了的地方

| 场景 | 能不能 | 原因 |
|---|---|---|
| 浏览器、QQ、记事本、系统设置、应用商店 | ✅ 可以 | 标准输入框 |
| **微信聊天框（安卓）** | △ 要配合 | 需同时打开一个读屏服务，见下方说明 |
| **游戏（Unity / UE 那类）** | ❌ 不行 | 画面是引擎自己画的，系统里没有可操作的控件 |
| **MT 管理器这类自绘编辑器** | ❌ 不行 | 同上，输入框不是标准控件 |

### 安卓版微信：要同时开一个读屏服务

微信内部有一份「可信读屏」名单，只有名单里的服务（比如系统自带的
TalkBack）才能读取聊天输入框。第三方应用不管申请什么权限，都不在名单里。

所以用法是：

```
设置 → 无障碍 → TalkBack → 打开
然后回微信正常打字
不用了记得关掉
```

> ⚠️ 读屏开着的时候，手机操作方式会变：
> 单击 = 选中（只念一下，不会点下去）、双击 = 才是真正点击、滑动 = 要用两根手指。
> 这一点必须提前知道，不然会以为手机坏了。

应用「设置」页有一个「检查微信支持」按钮，点一下会告诉你读屏开没开，
没开就直接带你去设置。

> 早期版本的结论是「微信拿不到输入框节点，做不到」。那个结论是错的 ——
> 不是 API 不够用，是微信不把节点交给不在名单里的服务。

## 编译

### 电脑版（Windows / .NET Framework 4.8）

用系统自带的 `csc.exe`，不需要装 Visual Studio：

```powershell
cd pc
.\build-exe.ps1
```

### 安卓版

需要 Android SDK（`build-tools` + `platforms/android-34`）和 JDK。

```powershell
# 改一下 build-apk.ps1 顶部的 $Sdk 路径
.\build-apk.ps1
```

用的是手工构建链（`aapt2` → `javac` → `d8` → `zipalign` → `apksigner`），
没有 Gradle，所以仓库里没有 `build.gradle`。

**注意**：Android 11+ 要求 `resources.arsc` 以 STORED 方式打包并且对齐，
构建脚本里已经处理了这两点。

## 规则文件

`rules.txt` 就是个文本文件，记事本就能编辑。格式：

```
# 词语替换
谢谢你 => 谢谢你喵

# 句尾装饰
模板 = {后缀}{颜文字}
后缀 = 喵~
颜文字 = (=^･ω･^=)
```

参数名中英文都认，不区分大小写，中间的下划线 / 空格 / 点都可有可无。
