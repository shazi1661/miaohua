  ★ 已经堵上的口子

    pack-all.ps1 第 171 行改成了：

        if (Test-Path $hand) {
            Get-ChildItem $hand -File |
              Where-Object { $_.Extension -eq '.zip' -or $_.Extension -eq '.apk' } |
              Remove-Item -Force -ErrorAction SilentlyContinue
        }

    —— ★ 现在只删 .zip / .apk ✗ 其它目录一律不动 ✓
    —— ★ 顺手踩到的坑：Get-ChildItem -Include 不加 -Recurse 是不生效的
        ✗ 第一版改成 -Include 后旧包没删掉 ✗ 必须用 Where-Object 筛 ✓
